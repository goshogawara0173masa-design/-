マリオカート ワールド攻略ノート（Webアプリ）

内容
- コース別のサンダー位置記録（例：3-2）
- サンダーなしレースも含む位置別発生率
- ショートカット位置とメモ
- 端末内の自動保存（localStorage）
- JSONバックアップの書き出し・復元
- HTTPS公開時のオフライン用Service Worker

重要
1. iPhoneのSafariで使うには、まずHTTPS対応のWebホスティング先にこのフォルダの中身をアップロードしてください。
2. 公開したURLをSafariで開き、共有ボタン →「ホーム画面に追加」を選びます。
3. 記録はそのiPhoneのSafari/Webアプリ内に保存されます。別の端末とは自動同期されません。
4. Safariの「履歴とWebサイトデータを消去」などで記録が消える場合があります。定期的にアプリの「保存・バックアップ」からJSONを書き出してください。
5. 現在のコース名とマップは仮データです。ゲーム内の公式コース名・正確なマップを反映するには、別途データの追加が必要です。
6. このZIPを直接開くだけでは、ホーム画面追加やService Workerによるオフライン機能は完全には動きません。HTTPSで公開して使用してください。
